# Changelog

## 0.1.0

- Named IPv4 gateways and IP/CIDR/DNS destination management.
- Root CLI with immediate reconciliation and read-only human/JSON status.
- Persistent systemd daemon with periodic DNS refresh and restart recovery.
- Multi-address DNS support, last-known-address retention, and ownership-scoped cleanup.
- One-line versioned installation, uninstall, and source pinning.
- Unit tests, isolated kernel integration tests, CI, and release archives with checksums.
